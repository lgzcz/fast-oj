# 客观题（单选自测）

服务端即时判分的单选自测，和判机、比赛、Rating 完全分开：没有用例、没有队列、
没有部分分，结果只属于做题的人自己。

## 权限

- 浏览公开的客观题：任何人。
- 新建：`problem.create`。
- 编辑 / 删除：作者或 `problem.edit.any`。
- 未发布的题（新建时不勾「所有人可见」）只有作者与 `problem.edit.any` 能打开；
  其他人访问详情与交卷都得到 404，列表里也不出现。

## 题目格式

创建/编辑页只有一个多行文本框，每行一道题：

```
题目|选项A|选项B|选项C|答案字母
```

- 选项 2..8 个，答案写 `A`..`H`，对应选项顺序；大小写都认。
- 题目最长 500 字，选项最长 200 字，最多 100 道题；整套说明最长 32768 字。
- 空行跳过；空题目、空选项、答案越界、字段不足都会在保存前拒绝，不会半套落库。
- 编辑是**整组替换**题目；已有的 `objective_attempts` 记录保留，但下次打开时会按
  新题重算显示（旧得分不再对应新题，所以页面提示按新题重新判分）。

## 作答与判分

- 登录用户每道题选一个选项；没选或选项越界一律按错。
- `POST /objective/{id}/answer` 在服务端比对答案，每题 1 分，立刻返回
  「答对 / 答错（你选 X，正确 Y）」。
- 每次交卷都会更新 `objective_attempts` 的得分与作答，并把 `attempts` 加一；
  页面显示上次得分与第几次作答。可以反复重做，不限制次数。
- 游客可以读题与选项，但看不到作答表单，也不会看到正确答案。

## 边界

- 它不是比赛：不进排行榜、不计 Rating、不影响积分。
- 它不做防作弊：答案在提交前不会下发，但反复重做必然能凑出满分，这是自测的定位。
- 它不代替题解：需要解析就写在题面说明里（支持 Markdown + KaTeX）。

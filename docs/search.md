# 全局搜索

`/search?q=` 同时查四类公开内容，每类最多 10 条：

| 类别 | 匹配字段 | 可见性 |
|------|----------|--------|
| 题目 | 编号、标题 | 只出现公开题；持 `problem.edit.any` 的人能看到隐藏题 |
| 文章 | 标题、正文 | 只出现已发布文章；作者能搜到自己的草稿，`topic.moderate` 能看到全部 |
| 题单 | 标题、说明 | 只出现公开题单；作者能搜到自己的隐藏题单，`problem.edit.any` 能看到全部 |
| 用户 | 用户名、昵称 | 不含已注销账号 |

## 口径

- 没有分词、没有索引、没有相关性排序：就是 SQL `LIKE`，按 id / 编号排序。
  站点规模不大时这比维护一套索引便宜，也不会出现"索引与库不一致"。
- 不翻页：每类 10 条封顶；要更多就去各自的列表页（题库、专栏、题单都支持 `?q=`）。
- 私信、工单、剪贴板、群聊消息、提交详情**永远不参与**全局搜索。
- 查询里的 `%` 与 `_` 已转义，不会被当成通配符。
- 空查询只显示搜索框，不列出任何内容。

## 入口

导航栏「搜索」；首页的搜索框仍然只查题库，两者互不替代。

## 两步验证与登录设备

`/settings/security` 管两件事：登录时的第二道门，以及已登录设备的名单。

### 两步验证（TOTP）

- 点「开始设置」生成一枚随机密钥，按页面上的 otpauth 链接加进验证器（Authy、Google Authenticator、1Password 等），再输入验证器显示的六位码启用。
- 六位码按 RFC 6238：30 秒一步、HMAC-SHA1、±1 步容差；手机时间快慢一分钟以内不会把人挡在门外。
- 启用时生成 **10 枚一次性恢复码**，只显示这一次。恢复码只存 sha256，数据库被看到也换不回能登录的码；用过的恢复码立刻作废。
- 启用后，除当前浏览器以外的已登录设备会被退出，避免旧会话绕过第二道门。
- 关闭需要当前密码。

### 登录流程

密码正确后，如果账号开着两步验证，服务器不给会话，只给一张 10 分钟的挑战票（cookie 只发往 `/login/2fa`）。在那一页输入六位码或恢复码才建会话。同一张票连续输错 5 次即作废，需要重新登录。

### 登录设备

页面列出所有未过期会话：最近活动、登录时间、地址、客户端。可以单独让某一台退出，也可以「退出其他所有设备」。当前这台不受影响；要退出它请用导航栏的「退出登录」。

### Passkey / WebAuthn

本轮没有做 Passkey。它需要浏览器的 WebAuthn 仪式（挑战、CBOR 公钥、RP ID 与 HTTPS 部署约束），与本项目的零外部依赖取向冲突；TOTP + 恢复码已经覆盖"密码泄露后仍要第二把钥匙"的主场景。

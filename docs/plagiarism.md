## 查重（同题相似度）

`/admin/plagiarism` 是给持 `submission.view.any` 的人用的轻量查重页：填一个题目编号，比较这道题**已 AC** 提交的源码。

### 怎么比

- 只比同一道题、同一语言、不同用户的提交；同一个人的多份提交不会被配成一对。
- 源码先规范化：去掉注释、字符串内容、预处理行与空白，数字统一成同一个符号；然后取 4 个 token 的滑动窗口，算 Jaccard 相似度。
- 少于 20 个 token 的提交直接跳过（通常是空程序或模板尾巴），不参与比较。
- 默认列出相似度 ≥ 80% 的对子，最多 100 个，按相似度倒序。

### 它不做什么

**只报告，不自动处罚。** 不扣分、不封号、不标记提交。误伤主要来自公共模板与讲义骨架（快读、并查集），重命名变量或改写循环结构也会让分数明显下降。

看到高分之后，人工看两份源码与提交时间，再决定要不要走工单或封禁流程。

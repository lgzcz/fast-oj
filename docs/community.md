# 群聊、剪贴板与帖子投票

三个轻量社区扩展，各自独立，不共享权限模型。

## 群聊

- `/chat` 列出全部房间；**匿名可读**，登录后才能开房与发言。
- 开房：`POST /chat`，房间名 1..60 字，全站最多 100 个房间，每人每小时最多 5 个。
- 发言：`POST /chat/{id}`，纯文本 1..2000 字，每人每分钟最多 30 句。
- 删除：消息作者可删自己的；`topic.moderate` 可删任何消息与房间；房主可删自己的房间。
- 消息 **不渲染 Markdown**，也不把链接变成可点击的。原因是聊天不需要排版，
  而一旦渲染，就等于给任意登录用户开了一个可发链接的公开页面。
- 房间页每 20 秒自动刷新一次；输入框里有未发送的内容时跳过这次刷新，
  避免把正在打的字冲掉。刷新是整页重新取，没有 WebSocket。

## 剪贴板

- `/clipboard` 是登录用户自己的纯文本记事本，**只有本人可见**，没有分享入口。
- 每人最多 50 条，名字 1..60 字，正文最多 65536 字。
- 新建 `POST /clipboard`，保存 `POST /clipboard/{id}`，删除 `POST /clipboard/{id}/delete`；
  所有操作都带 `user_id` 条件，别人的 id 一律 404。
- 正文同样不渲染，页面上就是一段可编辑的 `<textarea>`。

## 帖子投票

- 发帖时展开「加一个投票」：一个问题（1..200 字）+ 每行一个选项（2..8 个，每个 1..100 字）。
  两项都留空就是普通帖子；只填一半会在发帖前被拒，不会先建帖再报错。
- 投票挂在帖子上，删帖时 `polls` 与 `poll_votes` 随外键级联删除。
- `POST /topics/{id}/vote` 需要登录；一人一票，再投一次是**改票**而不是加票。
- 页面显示每个选项的票数、百分比与总票数；匿名可以看结果，但看不到投票按钮。
- 没有截止时间、没有多选、没有匿名投票：这一版保持最小口径。

## 边界

- 群聊与剪贴板都不做敏感词过滤与图片上传；要发图走「我的图床」。
- 群聊不是私信：没有 @、没有未读计数、没有房间成员表；要一对一交流走 `/messages`。
- 投票结果按 `poll_votes` 现算，没有缓存；一个帖子最多 8 个选项，聚合查询很小。

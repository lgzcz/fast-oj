# 学术模式与隐身

`/settings` 的「隐私与展示」里有两个开关，和私信策略一起保存（`POST /settings/privacy`）。
两者都只改公开展示，不改判题、榜单、Rating、权限与审计。

## 学术模式（`academic_mode`）

- 访客打开你的个人主页时，只看到学术数据：解题数、提交数、积分、Rating、判定分布与已解出题。
- 隐藏：动态（TA 的动态）、最近提交、关注/粉丝、打卡、发私信与关注按钮。
- 本人、`submission.view.any` / `problem.edit.any`（题主视角）与 `feed.moderate` 看到的仍是完整页面。
- 它**只改个人主页**：`/submissions` 等公开列表仍按原有可见性规则展示提交。
  需要连列表一起收起的，用下面的隐身。

## 隐身（`stealth`）

- 只在**有比赛正在进行**时生效：`contests` 里存在一条 `start_at <= now < end_at`。
- 生效期间，你的动态不会出现在 `/feed` 与首页，你的提交不会出现在 `/submissions`、题目页的
  「最近提交」和个人主页；个人主页的动态与最近提交也一起收起。
- 本人始终看得到自己的内容；`submission.view.any` / `problem.edit.any` 与 `feed.moderate`
  不受影响。
- 最后一场比赛结束后，时间窗一过就自动恢复，不需要重启或手动刷新开关。

## 边界

- 隐身不是匿名：管理员照常能查到记录，提交详情页本身仍按 `PublicView` 的规则可访问。
- 学术模式不影响他人对你的关注关系，只是不在主页上展示计数与入口。
- 两个开关都没有 API，只有这张表单。

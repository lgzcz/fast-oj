## 图床、头像与封面

图片与题目/工单附件共用 `attachments/` 目录：磁盘上是随机文件名，库里只存相对路径。区别是**图片是公开资源**——知道 `/images/{id}` 的人都能看，不要拿它存私密材料。

### 类型与上限

- 只收 PNG / JPEG / GIF / WebP；按**内容识别**，不看扩展名。SVG 与 HTML 在落盘之前就拒绝，避免变成同源页面。
- 头像 ≤ 2MB，封面 ≤ 8MB，正文图 ≤ 8MB；每人最多 200 张。
- 响应带 `X-Content-Type-Options: nosniff` 与 `Content-Security-Policy: default-src 'none'`，缓存一天。

### 头像与封面

在 `/settings` 上传。每种只有一个当前槽位：上传新图后旧记录与旧文件一起删掉；删除当前图会退回上一张（如果还没删）。个人页用头像与封面渲染；没有上传时页面与之前完全一样。

### 正文图

`/images` 是个人图床：上传后复制 `/images/{id}` 贴进帖子、题解或动态的 Markdown 里。删除是硬删除，已经贴出去的链接会变成 404。

### 备份

图片在 `data/attachments/image/` 下，跟着 `data/` 一起备份。数据库只存路径，单独拷库不拷目录会得到一堆 404。

## Rating、虚拟比赛与周赛

### Rating（`/u/{handle}` 上的数字）

- 账号起始 1200。只有 host 在比赛设置里勾了「计入 rating」的比赛才会结算。
- 比赛结束后一分钟内由后台结算一次：按最终名次两两算 Elo（K=32），队伍赛中整队共享名次、每个队员各记一份。
- 每场只结算一次（`contest_ratings` 账本 + `rating_done` 标记）；重跑结算器不会二次加减。
- 虚拟比赛与封榜后的私密比赛不参与 rating；成绩被删除也不会回滚已结算的分数。
- 结算时会把比赛页上的「这场比赛的 rating 结算：1200 → 1216（+16）」显示给本人。

### 虚拟比赛

一场已经结束的比赛，可以用原来的时长重新打一次：

- 在比赛主页点「开始虚拟比赛」。需要先是这场比赛的成员（主办方除外）。
- 时长取原比赛时长，最多 6 小时；每场比赛同时只保留一场进行中的虚拟赛。
- 题目用普通题目页打开，提交是普通练习提交；虚拟赛页只统计**开始之后、结束之前**这些题上的提交，按赛制给分，不进正式榜、不参与 rating。
- 可以提前结束；到点之后新提交不再计入，页面显示「时间到」。

### 周赛

`/weekly` 收集 host 标成「周赛」的比赛。它**不自动排期**：每周的比赛仍由 host 创建，勾上「周赛」即可出现在这里，并在比赛列表上带「周赛」标记。

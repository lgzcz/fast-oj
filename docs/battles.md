## 对抗赛（Battle）

`/battles` 是围绕一道题的短时 PK。发起需要 `contest.create`；参赛是登录用户即可。

- 发起时填标题、题目（必须公开）、起止时间与是否公开。
- 加入在结束前有效；结束后不能再进，已有成绩保留。
- 榜按窗口内、这道题上的普通提交现算：最好得分高者在前，同分比提交次数，再按用户名稳定排序。每题满分取自题目用例总分。
- 提交走普通题目页，是练习提交；对抗赛不写 `contest_id`，不进正式比赛榜，也不参与 rating。
- 发起人或持 `contest.manage.any` 的人可以删除；删对抗不动题目与提交。

### 与 OI 对抗 / Hack 的差别

这一版只做 PK 与榜单，**不执行 Hack**：没有"提交一组攻击输入去卡别人的程序"的流程，也没有自定义测试点运行。那需要把选手提供的输入送进判机、再指定攻击对象，属于判题链路的新任务类型，没有在这轮落地。

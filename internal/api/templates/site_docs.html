使用说明

这一页只讲最短的路径；遇到问题请发求助贴或开工单。

账号

  • 注册：/register。站点开了发信时，注册后要去邮箱点验证链接；没收到可以在个人设置里重发。
  • 登录与退出：右上角的登录入口；退出在账号菜单里。
  • 修改资料、密码、配色与隐私：个人设置。配色只影响你自己看到的页面。
  • 忘记密码：登录页的找回密码会往账号邮箱寄一条 30 分钟、一次性的重置链接；站点没配发信时请找管理员。
  • 注销账号由管理员操作，删除后无法恢复。

做题与判题

  • 题库：/problems。可以按关键词、难度、标签、来源筛选；标着“未公开”的题只有出题人与管理员看得到。
  • 题面里的数学公式由本地 KaTeX 渲染，不依赖外部 CDN。
  • 提交语言以题目允许的为准；提交后结果会显示在提交列表与题目页上。
  • 判题详情能看到多少，由出题人设置的“判题详情透露级别”决定；出题人与运维始终看得到全部。
  • 判题口径或数据变了，旧提交不会自动改判；需要时由管理员重新判题。

比赛

  • 比赛列表：/contests。未公开的比赛需要加入码或由办赛人拉进来。
  • 赛制分 OI、IOI、ACM 三种，计分与排名口径按赛制执行。
  • 比赛进行中，比赛内题目与用例会冻结，避免边打边改；结束或开始前可以正常编辑。
  • 从比赛入口进入题目提交，才会算进那场比赛的榜单。

社区

  • 帖子：/topics，可以带题目发出求助贴；评论在帖子详情页。
  • 动态：/feed，跟着关注的人看最新发言。
  • 私信：/messages。工单：/tickets，需要管理员处理的问题走这里。
  • 排行榜：/rank。每天可以在首页打卡，连续天数会显示在个人主页。

遇到问题

  • 题目描述不清、样例有误：在题目页点“求助贴”，或在工单里带上题目编号。
  • 判题结果可疑：先看提交详情里的判题信息，再带上提交编号开单。
  • 账号与权限问题：开单时写清账号名与需要做的事，不要在公开帖里贴密码。

运维与二次开发看仓库里的 docs/；站点当前版本的用户可见变化见更新日志。

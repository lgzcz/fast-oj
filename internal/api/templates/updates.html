更新日志

只记用户能感知的变化；部署细节与完整提交记录在仓库里。

2026-11-22

  • 题库支持按难度、标签与来源筛选；难度与标签会显示在题目页与题目列表里。
  • 新增使用说明、本站更新日志与 sitemap.xml，不用登录也能读。
  • 题面、动态、简介里的数学公式改为随二进制发布的 KaTeX，不再从外部 CDN 取。
  • 提交详情页只刷新结果块，判题过程中不再整页重载。
  • 用例上传与判题程序包加了压缩预算：超过站点配置或内建上限会直接拒绝，而不是先解压再说。
  • 比赛进行中会冻结比赛内的题目与用例编辑，避免边打边改。
  • 权限：改角色需要 permission.manage；不能封禁或注销还持有管理侧权限的账号。
  • 题目支持文件 IO：成对填写输入/输出文件名（如 game.in / game.out），判机按文件比较，不再只看 stdout；样例页会标出这两个文件名。文件 IO 与交互题不能同时使用。
  • 提交里的 #pragma GCC optimize/target、_Pragma 与 __attribute__((optimize/target)) 不再能改写判题固定的编译口径，会按编译错误拒绝并写明原因。
  • 安全：管理操作与受限动作的审计写入加上每 IP 预算，避免被刷成写放大；会话过期记录会定期清理。

此前

  • 比赛支持 OI / IOI / ACM 三种赛制，榜单按各自口径计算。
  • 判机隔离：命名空间、只读根、seccomp 与资源限制；降级时会写进判题信息。
  • 首页打卡：漏卡会按 3 的幂扣连续天数，个人主页显示连续与累计天数。
  • 帖子支持求助贴与题目关联；私信、工单与动态并入导航。

再早的变化没有逐条搬上来；需要时看仓库的提交记录。
